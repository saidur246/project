Project Title
Online Shop Management System Using Java OOP
Module/Part
Product & Inventory Management
Class Name
Product
Main OOP Concept
Encapsulation and Data Hiding
1. Introduction
An Online Shop Management System is a software system that can be used to manage products available in an online store.
In this project, the Product class is responsible for storing and managing product information such as:
Product ID
Product name
Price
Category
Stock quantity
Description
The main OOP concept used in this class is Encapsulation.
Encapsulation means keeping the data of an object protected and providing controlled access to that data through methods.
In this program, all product information is declared as private. Therefore, other classes cannot directly change the product data. Instead, getter and setter methods are used to read and update the information.
2. Objectives
The main objectives of this project are:
To create a Product class for an online shop.
To understand encapsulation in Java.
To implement data hiding using private variables.
To use constructors to initialize product objects.
To use the this keyword.
To use getter methods to access product information.
To use setter methods to update product information.
To validate price and stock quantity.
To make the product class reusable in the complete online shop system.
